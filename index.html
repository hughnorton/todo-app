          Read / Watch links

          The PC refresh writes a links.json file (OneDrive → Documents → Miscellaneous → To Do). Import it here: only links this phone hasn't seen are added, and anything you've marked done or removed stays that way — so it's safe to archive the emails afterwards. Optionally set a sync URL and the app fetches it by itself when opened.

          Tip: emailing a link to yourself works too — the PC refresh adds it with a proper title, length and summary.
